ABSTRACT

Wildfires pose immense ecological and socioeconomic threats globally. This project presents an end-to-end machine learning system that ingests NASA VIIRS I-Band 375m active fire satellite data to predict wildfire risk. Using 23 engineered features across thermal, FRP, spatial, and temporal domains, four classifiers (Random Forest, XGBoost, LightGBM, and ANN) were trained and evaluated. LightGBM achieved the top accuracy of 93.1% (ROC-AUC: 0.98). The models are served via a FastAPI REST API and visualised through an interactive 3D Globe dashboard.

PROBLEM STATEMENT & DRIVING QUESTION

Driving Question: Can satellite thermal observations reliably classify wildfire risk into actionable severity levels (Low, Medium, High, Extreme) using multi-model machine learning?

  • Current Challenge: Static threshold rules miss complex interactions between thermal intensity, background temperature, and timing.
  • Impact: Delayed responses exacerbate fire spread and increase suppression costs.
  • Proposed Solution: A multi-model ensemble combining spatial clustering and cyclical temporal encodings for high-precision risk categorisation.

DISCUSSION & KEY FINDINGS
  • Feature Engineering Impact: Expanding from 5 raw features to 23 engineered features boosted Random Forest accuracy from 87.2% to 91.8% (+4.6%).
  • Cyclical Time Encoding: Sine/Cosine hour encodings effectively captured diurnal fire peaks without artificial midnight discontinuities.
  • Ensemble Consensus: Combining probability vectors across all 4 models reduced edge-case false positives between Low and Medium risk.
CONCLUSION & FUTURE SCOPE

Conclusion: Multi-model machine learning on NASA VIIRS data provides highly accurate, real-time fire risk classification. LightGBM delivered superior accuracy and efficiency, while the 3D Globe dashboard provides rapid spatial decision support.

Future Scope: (1) Integrate NASA FIRMS live streaming API. (2) Incorporate wind & fuel moisture weather data. (3) Deploy to AWS / GCP Cloud Run.
